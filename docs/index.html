01 Was ich baue

Vier Türen. Sie wählen nach Problem, nicht nach Technik.

  1. A

    Arbeit automatisieren

    „Wir tippen jeden Tag dasselbe ab.“

    Excel-Listen zusammenkopieren, Berichte jede Woche neu bauen, Daten zwischen Tools übertragen: Solche Abläufe ersetze ich durch ein Skript oder einen Workflow, der zuverlässig läuft und dokumentiert ist.

    3–8 Tage→
  2. B

    Zahlen sichtbar machen

    „Ich sehe erst am Monatsende, wo wir stehen.“

    Aus den Daten, die Sie schon haben, entsteht ein Dashboard mit den Kennzahlen, die für Ihre Entscheidungen zählen. Es aktualisiert sich selbst, statt jeden Monat neu gebaut zu werden.

    1–3 Wochen→
  3. C

    Neues Produkt testen

    „Wir haben eine Idee für eine Plattform oder App.“

    Aus Ihrer Idee für eine Web-App, eine Plattform oder eine App entsteht ein Prototyp, den echte Nutzer ausprobieren können. So sehen Sie nach wenigen Wochen, ob die Idee trägt, bevor ein großes Budget fließt.

    2–6 Wochen→
  4. D

    Website oder Shop

    „Unsere Seite ist alt“ oder „Wir wollen online verkaufen.“

    Eine schnelle, rechtssichere Website oder ein Shop mit Bezahlung, die Sie ohne Technikkenntnisse selbst pflegen. Gebaut auf Technik, die Sie nicht an mich bindet.

    2–4 Wochen→

03 Wie ich arbeite

Drei Regeln, an die ich mich halte.

  1. 1

    Klein anfangen

    Erst klein und an echten Beispielen testen, dann ausbauen.

  2. 2

    Belegt statt behauptet

    Keine KI-Ausgabe ohne Beleg und Prüfung, keine Änderung ohne Tests und grüne CI.

  3. 3

    Datenschutz von Anfang an

    Daten in der EU, AV-Vertrag, nur was nötig ist.
